# Clockwork Couriers (2-6 players, 60 minutes)

Players program delivery automatons that race across a steam-powered city.

## Setup
Each player takes an automaton miniature, a programming board with 5 slots, and 8 command tiles (2 each of Forward, Left, Right, Wait). Place 12 parcel tokens on the city map in the marked districts. The youngest player is first courier.

## Programming phase
Simultaneously, each player secretly places 5 command tiles face down on their programming board. When everyone has finished, reveal and execute commands slot by slot, with the first courier acting first in each slot.

## Collisions
If two automatons end a command on the same tile, both lose their next command and stay put. An automaton pushed off the map returns to its starting depot and drops any parcels it carries.

## Delivering
Pick up a parcel by ending a command on its tile. You can carry at most 2 parcels. Deliver by ending a command on the parcel's destination district; each delivery scores 3 points, or 5 points if it is the first delivery to that district.

## Winning
The first courier to reach 20 points ends the game at the end of that round. If several couriers pass 20 in the same round, the highest total wins.
